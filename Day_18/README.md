# To Do Application
this is a simple To Do app using json 
you can add, delete and update your tasks name and status. you can also see your tasks in a list format. this app is built using python and json.

## Challenge  task 

ability to save completed tasks in a separate file and also able to load the tasks from the file when the app is restarted.
sort the tasks based on their status (completed or not completed) and also sort them based on their name in alphabetical order.
iadd new field to the task called "due date" and also able to sort the tasks based on their due date.
