# instance method
class method and static method are two types of methods in object-oriented programming, particularly in languages like Python. 
They differ in how they are called and what they operate on.
for example, in python, 
instance methods are the most common type of method. 
They are defined within a class and operate on instances of that class. while class methods are defined with the @classmethod decorator and operate on the class itself rather than instances.
static methods are defined with the @staticmethod decorator and do not operate on either instances or the class. 
They are used for utility functions that don't require access to instance or class data.
